# 控制流
Python 的语法特色就是**缩进**和代码块使用**冒号**。比如 if-else 语法：
```py
if x < 0:
    x = 0
    print("Negative changed to zero")
elif x == 0:
    print("Zero")
elif x == 1:
    print('Single')
else:
    print("More")
```

## for 循环
Python 的 `for` 循环类似 Kotlin，没有 `for (int i, i < 10, i++)` 这种方式，而是在列表、字符串、`range()` 等序列上遍历。
```py
chars = ['a', 'b', 'c']
# 遍历序列
for c in chars:
    print(c, len(c))

# 遍历 range 生成的序列
for i in range(5):
    print(i)
```

## 循环的 else 子句
在 Python 中，`for` 和 `while` 循环都支持附带 `else` 子句，这是 Python 比较有特色的语法设计。规则是：**循环正常结束，就会执行 `else` 的代码，如果被 `break` 提前终止，`else` 块就不会执行。**

```py
for i in range(3):
    if i == 1:
        print("触发 break，提前退出")
        break
    print(f"循环中：{i}")
else:
    print("else：循环正常结束")

# 打印结果：
# 循环中：0
# 触发 break，提前退出
```

> 如果可迭代对象为空，循环体一次都不会执行，但这属于 “正常结束”（没有被 break 打断），因此 else 仍然会执行

## pass 语句
`pass` 是 Python 中的空操作占位语句，它本身不执行任何逻辑，唯一的作用是填补语法上必须存在代码块的位置，避免因代码块为空而触发语法错误。

```py
# 先声明函数，后续实现具体逻辑
def process_data(data):
    pass  # 待补充：数据清洗、转换逻辑

# 类中的空方法
class User:
    def login(self):
        pass  # 待实现登录校验逻辑
```

## 位置参数和关键字参数
在函数定义中，设定了默认值的参数叫做`关键字参数`，其他参数叫做`位置参数`。

普通位置参数既支持位置传参，也支持关键字传参：
```py
def add(a, b):
    return a + b

add(1, 2)         # 位置传参
add(b=5, a=3)     # 关键字传参，顺序可任意
```

关键字参数定义时必须位于无默认值的位置参数右侧，同时支持位置传参和关键字传参：
```py
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Tom")                 # Hello, Tom!
greet("Tom", "Hi")           # Hi, Tom!
greet("Tom", greeting="Hey") # Hey, Tom!
```

### 可变长参数（* 参数）
将调用时传入的所有多余位置参数，自动打包成一个元组（tuple）赋值给该变量，定义时必须位于普通位置参数右侧：
```py
def sum_all(*args):
    return sum(args)

sum_all(1, 2, 3)    # 6
sum_all()           # 0，传0个参数也合法
```

可以通过 `*` 对列表、元组等可迭代对象解包：
```py
nums = [1, 2, 3, 4]
sum_all(*nums)  # 等价于 sum_all(1, 2, 3, 4)
```

### 可变关键字参数（** 参数）
将调用时传入的所有多余关键字参数，自动打包成一个字典（dict）赋值给该变量。
* 定义时必须位于所有参数的最右侧
* 函数内部 kwargs 是字典类型，可按键取值、遍历
```py
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Tom", age=18, city="Beijing")
```

调用函数时，可用 `**` 将字典拆包成关键字参数传入：
```py
info = {"name": "Tom", "age": 18}
print_info(**info)  # 等价于 print_info(name="Tom", age=18)
```

### 特殊参数
默认情况下，参数可以按位置或关键字传递给函数，如果使用 `/` 则只能使用位置传参，如果使用 `*` 则只能使用位置传参。

`/` 符号左侧的参数只能通过位置传参：
```py
def add(a, b, /, c):
    return a + b + c

add(1, 2, c=3)       # 正确
# add(a=1, b=2, c=3) # ❌ 报错，a 和 b 不能用关键字传参
```

`*` 符号右侧的参数只能通过关键字传参：
```py
def create_user(*, username, password, role="user"):
    print(f"创建用户：{username}, 角色：{role}")

# 必须用关键字传参
create_user(username="admin", password="123456")
create_user(username="admin", password="123456", role="admin")
# create_user("admin", "123456")  # 报错，不能按位置传参
```

## 函数注解
函数注解用于给函数的参数、返回值附加元数据，比如可以用来做类型提示。（真正的类型检查，需要借助第三方静态工具、IDE智能检查）
```py
def add(a: int, b: int) -> int:
    return a + b

print(add.__annotations__)
# 输出：{'a': <class 'int'>, 'b': <class 'int'>, 'return': <class 'int'>}
```

> Python 函数注解是一套极简、无强制规范、仅做挂载的元数据语法，所有能力都由第三方生态定义。

# 错误和异常
```py
try:
    f = open("data.txt")
    num = int(f.readline())
except OSError:
    print("文件打开失败")
except ValueError:
    print("文件内容不是合法整数")
```

如果多个异常的处理逻辑完全一样，可以用元组合并写：
```py
try:
    # 一些操作
    pass
except (RuntimeError, TypeError, NameError):
    print("运行时出错，统一处理")
```

在异常类型后面加 `as` 变量名，可以拿到异常实例本身
```py
try:
    raise Exception("参数1", "参数2")
except Exception as e:
    print(type(e))       # 异常类型：<class 'Exception'>
    print(e.args)        # 异常参数元组：('参数1', '参数2')
    print(e)             # 直接打印异常信息（内置异常都做了优化）
```

`try` 也可以使用 `else` 语句：
```py
try:
    f = open("test.txt", "r")
except OSError:
    print("文件打开失败")
else:
    # 只有打开成功才会走到这里
    print(f"共 {len(f.readlines())} 行")
    f.close()
```

## finally 清理子句
```py
f = None
try:
    f = open("data.txt", "r")
    # 操作文件

finally:
    if f:
        f.close()  # 无论是否报错，文件都会关闭
```

```py
try:

```

# 作用域
在函数内部对变量执行赋值操作（=、+=、-= 等），Python 就会默认把这个变量当成当前层的局部变量，不会去外层查找。可以使用 `global` 和 `nonlocal` 来改变行为。

## global
```py
count = 0

def add():
    # count += 1  # ❌ 报错：UnboundLocalError，因为 Python 认为 count 是局部变量，但还没定义就使用了
    global count  # ✅ 声明：count 是全局变量
    count += 1    # 修改的是全局的 count

add()
print(count)  # 输出：1
```

如果只是读取、不赋值，Python 会自动向上查找到全局变量，不需要加 `global`：
```py
name = "Tom"

def greet():
    print(name)  # ✅ 正常运行，只读不赋值，自动找到全局变量

greet()
```


## nonlocal
用于嵌套函数（闭包）场景，作用是：声明变量来自「外层函数的作用域」，而不是当前函数的局部变量，也不是全局变量。

```py
def make_counter():
    count = 0
    
    def increment():
        # count += 1  ❌ 假如直接这样写，会报错：UnboundLocalError

        nonlocal count  # ✅ 声明：count 来自外层函数
        count += 1
        return count
    
    return increment

counter = make_counter()
print(counter())  # 1
print(counter())  # 2
```


## 方法
方法包含实例方法、类方法、静态方法。

```py
class Person:
    def __init__(self, name):
        self.name = name
    
    def say_hello(self):  # 实例方法
        print(f"你好，我是{self.name}")

    species = "人类"
    

    # 类方法，使用 @classmethod 装饰器，第一个参数为 cls
    @classmethod
    def change_species(cls, new_name):
        cls.species = new_name  # 修改类属性

    # 静态方法，使用 @staticmethod 装饰器，既不属于实例也不属于类，就是放在类命名空间里的普通函数

```

## 访问控制
1. 普通命名：`name`：公有属性 / 方法，外部可自由访问
2. 单下划线前缀：`_name`：建议不要在类外部直接访问，没有强制
3. 双下划线前缀：`__name`：Python 会自动做名称改写，实际存储为 `_类名__属性名`，目的不是实现私有，而是避免子类和父类的属性名冲突。
4. 前后双下划线：`__xxx__`：系统内置的魔术方法 / 属性，比如 `__init__`、`__str__`、`__len__`，有特殊语义，不要自定义这类命名。

## 继承
```py
# 父类（基类）
class Person:
    def __init__(self, name):
        self.name = name
```

## 多态
Python 是动态语言，多态不依赖严格的继承关系，所以只要一个对象有对应的方法，不管它属于哪个类，都可以被调用：
```py
class Cat:
    def speak(self):
        print("喵喵")

class Dog:
    def speak(self):
        print("汪汪")

# 统一调用接口，不关心具体类型，只要有 speak 方法即可
def make_sound(animal):
    animal.speak()

make_sound(Cat())
make_sound(Dog())
```

## @property
可以把方法伪装成属性，实现 Python 风格的 getter /setter，既可以做参数校验，又能保持属性式的调用方式。

```py
class Person:
    def __init__(self, age):
        self._age = age
    
    @property       # getter：读取属性
    def age(self):
        return self._age
    
    @age.setter     # setter：修改属性，可加校验
    def age(self, value):
        if value < 0:
            raise ValueError("年龄不能为负")
        self._age = value

p = Person(20)
print(p.age)    # 像属性一样读取
p.age = 25      # 像属性一样赋值，自动走校验逻辑
```

# yield 生成器
`yield`其实就是协程的一种形式。

```py
def demo_gen():
    print("执行第1段代码")
    yield 1  # 第1个暂停点
    print("执行第2段代码")
    yield 2  # 第2个暂停点
    print("函数全部执行完毕")

g = demo_gen()

# 第一次执行 next 方法，推动函数执行到第一个 yield 暂停点
res1 = next(g)
# 控制台输出：执行第1段代码
print(res1)  # 1

# 第二次执行 next 方法，推动函数执行到第二个 yield 暂停点
res2 = next(g)
# 控制台输出：执行第2段代码
print(res2)  # 2

# 第三次执行 next 方法，推动函数执行完毕
next(g) # 此时 next() 会抛出 StopIteration 异常，标志迭代彻底结束。
```

> 可以看出来，如果函数只有一个 yield 暂停点，其实就相当于 Kotlin 的挂起函数，如果有多个 yield 暂停点，就相当于 Kotlin 的 Flow。

## send
除了使用 `next` 可以推动执行到下一个 yield 点，使用 `send` 也可以，区别是 `send` 可以传递值
```py
def echo_gen():
    print("生成器启动")
    msg = yield "hello"  # yield 表达式本身可以接收值，赋值给 msg
    print(f"收到消息: {msg}")
    msg2 = yield f"你发了：{msg}"
    print(f"收到第二条: {msg2}")

g = echo_gen()

# 第一次必须用 next(g) 或 g.send(None) 启动，执行到第一个 yield
first = next(g)  # 输出：生成器启动
print(first)     # hello

# 发送数据，恢复执行
second = g.send("你好呀")
# 输出：收到消息: 你好呀
print(second)    # 你发了：你好呀
```

## 遍历
生成器本质就是迭代器：
1. 它实现了 `__next__()` 方法，可以被 `next()` 逐次调用
2. 迭代耗尽时会抛出 `StopIteration` 异常，标志结束

Python 里所有「遍历行为」（for 循环、list() 强转、sum() 聚合等），底层都是在自动执行这套迭代器协议，所以这些方式都可以遍历地执行生成器。

比如使用 `for` 循环，就不用手动调用 next。
```py
def gen_num():
    yield 1
    yield 2
    yield 3

# 自动逐次执行 yield，拿完所有值自动结束
for num in gen_num():
    print(num)
```

## yield from：简化嵌套迭代
`yield from` 可以直接遍历一个可迭代对象，把里面的元素逐个 `yield` 出来，简化嵌套生成器的写法。
```py
def flat_gen():
    yield from [1, 2, 3]  # 等价于 for x in [1,2,3]: yield x
    yield from "ab"       # 等价于 for x in "ab": yield x

print(list(flat_gen()))  # [1, 2, 3, 'a', 'b']
```

# async / await
Python 3.5 引入了 `async` 和 `await`。

任何对象只要实现了 `__await__()` 方法，就能被 `await`。`__await__` 必须返回一个迭代器。


实现一个基本的 `__await__()` 方法：
```py
import asyncio
from concurrent.futures import Future

class MySleep:
    def __init__(self, seconds):
        self.seconds = seconds
    
    def __await__(self):
        # 创建一个 Future，告诉事件循环"我还没完成"
        future = asyncio.get_event_loop().create_future()
        
        # 用 call_later 注册一个回调，到时间后 set_result 唤醒
        loop = asyncio.get_event_loop()
        loop.call_later(self.seconds, future.set_result, "醒了！")
        
        print(f"  [MySleep] 挂起，等待 {self.seconds} 秒...")
        
        # yield 这个 future 出去
        # 事件循环会等待这个 future 完成，然后唤醒协程
        result = yield future
        
        print(f"  [MySleep] 被唤醒，收到: {result}")
        return result

async def main():
    print("开始等待...")
    result = await MySleep(2)
    print(f"完成！结果: {result}")

asyncio.run(main())
```

> 但实际开发中，我们一般会直接使用 `asyncio` 提供现成的 `async` 方法，不需要自己手动实现 `__await__()`。

这里把一个普通的同步耗时函数包装为异步函数：
```py
import asyncio
import time

# 这是一个普通的同步函数，会阻塞主线程
def blocking_task(duration):
    print(f"开始执行耗时任务... (需要 {duration} 秒)")
    time.sleep(duration)  # 模拟耗时操作
    print("耗时任务完成")
    return "任务结果"

async def main():
    print("1. 准备开始")
    
    # 获取当前的事件循环
    loop = asyncio.get_running_loop()
    
    # 使用 run_in_executor 包装同步函数
    # 第一个参数 None 表示使用默认的线程池 (ThreadPoolExecutor)
    # 后面的参数是传给 blocking_task 的参数
    result = await loop.run_in_executor(None, blocking_task, 2)
    
    print(f"2. 拿到了结果: {result}")

asyncio.run(main())
```

把一个回调函数包装为异步函数：
```py
import asyncio

# 模拟一个老旧的异步库，只支持回调
def old_library_async_operation(callback):
    print("旧库：开始操作...")
    # 模拟异步延迟
    asyncio.get_event_loop().call_later(2, lambda: callback("旧库的数据"))

# --- 包装层 ---

async def modern_wrapper():
    # 1. 创建一个 Future 对象 (相当于 Kotlin 的 CancellableContinuation)
    future = asyncio.get_running_loop().create_future()
    
    # 2. 定义回调函数，当旧库完成任务时，设置 Future 的结果
    def on_complete(data):
        print(f"回调被触发，收到数据: {data}")
        future.set_result(data)  # 唤醒协程
    
    # 3. 调用旧库，传入我们的回调
    old_library_async_operation(on_complete)
    
    # 4. 挂起当前协程，等待 Future 被 set_result
    print("包装器：正在等待旧库返回...")
    result = await future
    print("包装器：拿到结果，返回给上层")
    return result

# --- 使用层 ---

async def main():
    print("开始")
    data = await modern_wrapper()
    print(f"最终结果: {data}")

asyncio.run(main())
```

## 取消和异常
Python 的取消也是协作式的，会在协程到达下一个 `await` 点时，抛出一个 `CancelledError` 异常。

```py
import asyncio

async def long_task():
    try:
        for i in range(10):
            await asyncio.sleep(1)  # 取消信号在此触发
            print(f"进度: {i+1}/10")
    except asyncio.CancelledError:
        print("执行清理...")
        raise  # 必须重新抛出，否则任务被视为"正常完成"

async def main():
    task = asyncio.create_task(long_task())
    await asyncio.sleep(2)
    task.cancel()
    try:
        await task
    except asyncio.CancelledError:
        print("任务已取消")

asyncio.run(main())
```

> `CancelledError` 继承自 `BaseException`（而非 Exception），因此普通的 except Exception 不会捕获它。这个故意的设计是为了让取消不被通用异常捕获意外吞掉。

### ExceptionGroup 和 except*
多个并发任务可能同时抛出不同类型的异常，`except` 只能处理一个。而 `except*` 可以遍历异常组中的每个异常，分别匹配对应的处理分支：
```py
async def task_a():
    raise ValueError("参数错误")

async def task_b():
    raise TypeError("类型错误")

async def main():
    try:
        async with asyncio.TaskGroup() as tg:
            tg.create_task(task_a())
            tg.create_task(task_b())
    except* ValueError as eg:
        print(f"ValueError: {eg.exceptions}")
    except* TypeError as eg:
        print(f"TypeError: {eg.exceptions}")
```

## 结构化并发
使用 `asyncio.TaskGroup` 可以很容易地实现结构化并发，一个任务错误，会自动取消全部。

```py
import asyncio


async def worker(name: str, delay: float):
    try:
        print(f"[{name}] 启动")
        await asyncio.sleep(delay)
        if name == "B":
            raise ValueError(f"{name} 出错了！")
        print(f"[{name}] 正常结束")
    except asyncio.CancelledError:
        print(f"[{name}] 被取消了")
        raise  # 必须重新抛出，别吞掉


async def main():
    try:
        async with asyncio.TaskGroup() as tg:
            tg.create_task(worker("A", 2.0))
            tg.create_task(worker("B", 0.5))   # 会先失败
            tg.create_task(worker("C", 3.0))
    except* ValueError as eg:
        # 3.11+ 用 except* 处理 ExceptionGroup
        for exc in eg.exceptions:
            print(f"捕获到异常: {exc!r}")

    print("main 继续执行")


asyncio.run(main())
```
